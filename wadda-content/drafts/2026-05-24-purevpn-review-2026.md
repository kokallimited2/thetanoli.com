## Features Deep Dive

### Dedicated IP ($2.50/month add-on)
A dedicated, static IP that only you use. Useful for:
- Whitelisting in business systems
- Avoiding CAPTCHA loops
- Consistent geolocation for streaming and banking

### Split Tunneling
Available on Windows, Mac, iOS, and Android. Choose which apps use the VPN and which connect directly — useful for streaming through the VPN while gaming or banking through direct connection.

### Port Forwarding
Available on select servers. Useful for:
- Torrenting (improves peer discovery)
- Remote access to home systems
- Gaming servers

The port forwarding setup is more manual than competitors — you must select specific server locations that support it.

### Kill Switch
PureVPN has two kill switch modes:
- **Internet Kill Switch** — Blocks all internet if VPN drops
- **App-Level Kill Switch** — Blocks specific apps when VPN drops

Both work reliably in testing.
