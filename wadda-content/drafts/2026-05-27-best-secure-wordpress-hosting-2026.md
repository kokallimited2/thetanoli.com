## FAQ

### What makes managed hosting more secure than shared hosting?
Managed hosts handle server patches, WAF configuration, DDoS protection, and automated backups — all things you'd have to configure yourself on shared or VPS hosting.

### Is SSL enough for WordPress security?
Not even close. SSL encrypts data in transit. You still need a WAF, backups, malware scanning, and automatic updates — which managed hosts provide.

### Should I leave cPanel after the recent breaches?
If you're comfortable managing server security yourself, cPanel is still viable with prompt patching. But after two critical CVEs in one month, managed hosting is the safer bet for most site owners.

### Can I migrate from one host to another?
Yes. Most managed hosts offer free migration services. WP Engine and Kinsta both include free migration with any plan.

### How often should I back up my site?
Daily at minimum. Hosts like Kinsta back up 6x daily. Pair with an off-site backup solution for disaster recovery.
