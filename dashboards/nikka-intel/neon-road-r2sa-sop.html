📋 SOP — How to Replicate This Model

Step 1: Qualify the Investor

  • Send investor application form
  • Request proof of funds
  • Qualify → move to step 2. Fail → thanks, next.

Step 2: Source Deal

  • Pitch agent using script (never say Airbnb)
  • Secure corporate let from landlord (3-7yr term)
  • Pay £500 agent fee if needed
  • Structure deal: fixed rent + maintenance cap + cleaning schedule

Step 3: Package & Present

  • Send deal brochure to qualified investor
  • Include case studies, projections, T&Cs
  • If interested → reservation form + invoice

Step 4: Close

  • 24-hour cooling-off period
  • After 24h: non-refundable
  • Proceed with compliance, interior design, furnishing
  • Handover to SA operator

⚠️ Key Risks to Avoid

  • Never guarantee profitability or occupancy
  • Client must do their own due diligence (written in T&Cs)
  • Check property licensing for short-term lets in target area
  • Verify landlord mortgage terms allow subletting
  • Ensure proper HMO licensing if required
  • Protect against Renters Reform Bill / Section 8 changes
