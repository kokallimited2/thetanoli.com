🧠 Current Best Framework

Stage 0 — 2-Minute Triage

"If you spend 5 hours on every property, you can't look at enough. You need a quick way to rule out the duds."

  • Purpose: Eliminate 80%+ of listings before detailed analysis begins. Prevents time waste on bad deals.
  • 4-factor quick score (0-10): Price-fit (2.5pts) × Refurb-signal (2.5pts) × Area-demand (2.5pts) × Quick-yield (2.5pts)
  • Pass threshold: ≥ 6/10 → proceed to Stage 1. Below 6 → reject immediately with a single-line reason.
  • Refurb signal: "Requires modernisation" / "needs updating" / probate / 90+ days = good signal. "Recently refurbished" = no value-add → drop score by 2.
  • Quick yield: Estimated rent ÷ price. If gross yield < 5% for WM BTL → score 0 for this factor.
  • Efficiency check: Aim to triage 30+ properties per session, only 5-10 pass to Stage 1.

Stage 0a — Institutional 5-Filter Pre-Screen (NEW — 2026-05-20)

"The operators winning right now are not finding magic deals. They have a system that rejects 95% of what crosses their desk in under 30 seconds." — Daniel Brody (adapted)

#FilterRuleRationale
1Purchase price vs. ARV≤75% of after-repair valueForces equity, sets refinance ceiling. Above 75% = no margin for surveyor gap.
2Price-to-rent ratio<100× monthly rentBelow 100× = math works. Above 100× = speculation on growth, not cashflow.
3Stabilized net yield≥6% net after all costsNeed ≥50bps margin above 2026 debt cost (5.5% stress rate). Below = negative leverage.
4Rent fundamentalsLet-agreed ratio ≥35%Government-backed or anchor-institution demand = underrated moat.

All 5 must pass. Fail any → REJECT at Stage 0a, before the 4-factor triage. This eliminates ~95% of listings in under 30 seconds per property.

Stage 0b — Two-Loan Alignment Check (NEW — 2026-05-20)

"BRRRR isn't a single loan. It's a two-loan sequence and the two need to be aligned from day one." — HomeAbroad

  • Pre-qualify the refinance exit before bridging commitment. Get a BTL/DSCR underwriter to confirm Loan 2 terms at projected ARV before signing Loan 1. The #1 mistake is closing on bridging without this check.
  • Six-month rule diagnosis: Mainstream lenders (BM Solutions, The Mortgage Works, Paragon) enforce 6 months from Land Registry registration. With backlogs, budget 8-9 months bridging. Workaround: Specialist lenders with manual underwriting can refinance within weeks of completion if refurb is substantial and well-documented. This is worth a 2-3% premium in borrowing cost for the velocity gain.
  • Stress the proceeds, not just the rate: Model refinance proceeds at 85% of standard underwriting (leverage collapse adjustment). If the deal only works at 2022-era proceeds, reject.
  • Ideal structure: One lender who handles BOTH bridging and BTL — seamless transition eliminates the gap period entirely.
  • Exit planning: If the refinance exit fails, does the deal work as a forced sale? If not, you don't own the property — the bridging lender does.

Stage 0c — Blind Spot Audit (NEW — 2026-05-22)

"Blind confidence is often more dangerous than uncertainty." — Simon Zutshi (PIN, 25+ years)

What it is: A structured pre-modelling gate that forces systematic assumption-challenge BEFORE any financial inputs are used. The #1 cause of bad deals is not bad maths — it's optimistic inputs entered into otherwise correct formulas.

4 checks — all must pass:

  1. Input Uncertainty Quantification — For every numeric input (rent, refurb cost, void rate, ARV, timeline, mortgage rate), state three values: optimistic / base / pessimistic. If you can't estimate a range for any key input, label it SPECULATIVE — the analysis is not reliable.
  2. Source Quality Audit — Grade each input's data source: A-grade (written quotation / official data), B-grade (well-researched estimate, 3+ comps), C-grade (guess, single data point). If ANY key input (refurb, ARV, rent) is C-grade → the analysis is speculative, not analytical.
  3. "What Would Change My Mind" Statement — Write one explicit sentence defining exit criteria before modelling: e.g., "I would reject this BRRR if the surveyor values below £170k." Forces pre-defined exit criteria rather than post-hoc rationalisation.
  4. Blind Confidence Flag — If every input in the base case is at the optimistic end of the range, label the deal 🟡 BLIND CONFIDENCE — Full stress testing required before proceeding.

Step 1 — Strategy Before Deal (REVISED 2026-05-18)

"Professional investors define the strategy before analysing the deal. There is no single 'good deal' in isolation." — uncommondeal.com

  • Define investment strategy FIRST — Before touching any numbers, state which strategy this property is being analysed for. A property that works for BTL may be unsuitable for a BRRR, flip, or HMO.
  • Property must be under market value (UMV) or distressed — motivated seller who values speed over price
  • Check for distress signals: probate, sitting tenant, "requires modernisation", multiple price reductions, 90+ days on market
  • Reject: "recently refurbished" (no value add), leasehold under 80 years, unmortgageable construction
  • Priority targets: subsidence (30-50% discount, £15-50k fix), probate, structural distress, cash-only condition

Step 1a — Refinance Readiness Check (REVISED 2026-05-19)

"Exit blockers discovered at refinance are catastrophic. Assess refinance criteria before committing to purchase." — Evolve Finance

  • EPC Rating: Must be ≥ C post-refurb, or budget ~£10k for upgrade. Lenders increasingly enforce minimum EPC thresholds.
  • RICS ESG 4th Edition (April 2026) — NEW MANDATE: Surveyors are now explicitly mandated to quantify ESG gaps. No more favourable assumptions about thermal performance. If property fails 2030 EPC C mandate, surveyor must discount capital value by remediation cost. (Source: Adam Lawrence / RICS)
  • Compliance Certificates: Building regs, electrical (EICR), gas safe, fire safety. If pathway unclear → HIGH RISK.
  • Licensing: HMO license pathway? Article 4 status? Any known council-level blockers? Must be resolvable at known cost.
  • Mortgageability: Standard construction? No cladding? Lease >80 years? Non-standard construction flags lenders immediately.
  • Valuation Pack Strategy (NEW): Prepare a RICS-compliant Valuation Pack before surveyor visit: complete schedule of works, building control completion certificates, structural warranties, hyper-local comparable sales aligned to RICS Red Book standards. Without this, surveyor defaults to conservative AVM that undercuts valuation by 5-15%. A strong Valuation Pack "completely removes the surveyor's ability to default to a conservative automated valuation model." (Source: Adam Lawrence)
  • Score: If any fail → label as REFINANCE BLOCKER. Reject unless >20% discount to compensate for risk.
  • Refinance Cycle Impact (2026-05-18): 1.8M UK mortgages due to reset by end of 2027. ALL BRRR deals must model post-refi cashflow at current (2026) rates plus 0.5% buffer. If the deal only works at lower-than-current rates, reject.
  • This replaces the old "just check mortgageability" — it's now a formalised gate before any financial modelling.

Step 1b — HMO-Specific Workstream Gate (NEW — 2026-05-21)

"BRRRR is not just about creating value. It is about holding a property that works well enough for the refinance and the rental model to stay stable afterwards." — HMO Architects (G. Patania)

When strategy match identifies HMO potential, insert this 5-gate mandatory workstream between Step 1a and Step 2. All 5 gates must pass before any financial modelling for HMO.

3. Building regsFire strategy (compartmentation, FD30s, alarms, emergency lighting)? EICR? Gas safe? Previous works certified?Property needs major structural changes (staircase, fire escape, separate entrance) that don't fit within existing layout

Key principle from HMO Architects: Planning, licensing, building regs, and compliance are SEPARATE gates — they are NOT the same thing and do NOT overlap. Missing any one can kill the refinance case even if the property looks well-refurbished.

Additional check for HMO BRRRR specifically: Layout and compliance matter as much as the refurb budget. If bedrooms are too tight, shared space is poor, or fire strategy is unresolved — the property will underperform even after a good-looking refurb. Get layout verified by a professional before committing capital.

Step 2 — True Market Value (Comparable Evidence) (REVISED 2026-05-19)

  • Minimum 3 comparables within ¼ mile, similar size/type/condition, sold within 12 months
  • Use Rightmove Sold Prices + Land Registry for official data. Avoid estate agent opinions and online valuation tools as primary sources.
  • EPC register hack: exact square footage for like-for-like comps
  • Apply evidence gap penalty for EPC below C (2030 mandate) — discount by estimated compliance cost (£10k max)
  • External condition penalties: moderate roof = 5-8% adjustment, structural = up to 20%
  • Valuation Gap Penalty (NEW): For BRRR refinance calculations, apply a 5-15% penalty to ARV. Surveyors value 5-15% below open market comparables due to lending methodology. Use 0.85-0.95 factor depending on market liquidity. Three independent sources converged on this gap (Property Filter, Evolve Finance, Adam Lawrence). Example: £180k ARV → surveyor at £165k → £11,250 extra capital trapped.
  • GDV Stress Test: Model GDV at 3 scenarios — Target / Bear (-10%) / Stress (-15%). Deal must survive Bear GDV (break-even or better).
  • Yield Compression Check (NEW): Test rental income against stress test rates (5.5-7%) not product rates (4-5%). Higher LTVs frequently fail lender rental coverage (min 125-145%) even when lower LTVs pass. Model at the LTV that passes coverage, not the LTV that maximises extraction.

Step 3 — Rental Demand & Achievable Income

  • Search Rightmove lettings with 'let agreed' ticked — 35%+ let-agreed ratio = strong tenant demand
  • Check 3+ comparable rents for the post-refurbished property. Use actual let-agreed prices, not advertised rents. Overestimating rent is the fastest way to destroy deal viability.
  • Apply achievable rent (not aspirational) backed by letting evidence. Consider tenant demand depth, local affordability constraints, void assumptions.
  • Lenders now scrutinise rental affordability — must be sustainable, not a short-term spike
  • Anchor institutions: hospitals, universities, corporate campuses, transport links = built-in demand

Step 4 — Full Cost Waterfall (Residual Method) (REVISED 2026-05-19)

  • Start from post-refurb GDV, deduct ALL costs, deduct target profit (20% min), deduct contingency (15-20% of refurb)
  • Full cost waterfall MUST include: purchase price + SDLT (+3% surcharge) + legal (£1.5k) + broker (£500) + survey (£500) + valuation + sourcing fees (if applicable) + refurb + contingency (15-20%) + finance costs (bridging interest, arrangement fees, exit fees, interest during voids) + holding costs + exit costs (agent fees, CGT, selling legal)
  • Detailed Cost Table Cash Flow (NEW): Replace simple "Rent − Mortgage" with full cost model:
    • Management (12% of gross rent) — Note: This is NOT a cost, it's insurance. Self-management costs MORE in hidden costs (£4,500-41,900/yr vs £1,400-4,500 professionally managed). (Sources: 10 Acre, Link Property)
    • Maintenance Reserve (10% Preventive / 12-15% Reactive / 15-25% Deferred/First-Year of gross rent). Use 10% Preventive as base case. If property "requires modernisation," first-year maintenance will be in the Deferred tier. "Maintenance should be viewed not as an expense, but as income protection." (Source: Link Property)
    • Void Allowance (8.33% = 1 month per year) — "One month without rent = 8-10% loss in yearly income for that property." (Source: Link Property)
    • Insurance (£35/mo typical)
    • Compliance amortised (£25/mo typical: gas, EPC, electrical, licences)
    • Critical: Model mortgage at stress test rate (5.5-7%), not product rate (4-5%). The gap between "Rent − Mortgage" and "Rent − All Costs" routinely exceeds 100% of expected surplus. (Source: Property Filter)
  • Cash Flow First Test: If the deal does not produce a monthly surplus at today's interest rates, reject it. Future rate cuts should improve a deal, never be the reason it works.
  • Debt Coverage Ratio (DCR): DCR = Net Rental Income ÷ Annual Mortgage Payments. Target ≥ 1.25. Below 1.0 → negative cashflow.
  • Cash Buffer: Maintain 20-25% cash reserves. Calculate as: (Total Monthly Costs × 6 months) + (20% of refurb budget).
  • Overestimate timelines by 50% — holding costs are the black hole that kills deals
  • Six-month rule: High Street BTL lenders enforce 6 months from Land Registry registration. With backlogs, budget 8-9 months of bridging. Specialist lenders with manual underwriting can refinance within weeks.
  • Capital Trap Ratchet Modelling (NEW — 2026-05-20): Refurb overruns and surveyor valuation gaps do NOT compound linearly — they multiply. A 15% refurb overrun + 7.5% surveyor gap creates a 50-80% larger capital deficit than either alone. Model them TOGETHER with a Ratchet Scenario column in every BRRR Deal Card alongside Best/Base/Worst.

Step 5 — Three-Layer Profitability (REVISED 2026-05-19)

  • Show ALL three: Gross Yield %, Net Yield %, Cash-on-Cash ROI %. Headline yields are misleading without context.
  • Also model IRR for cross-property comparison where relevant.
  • Returns must be assessed relative to risk and capital deployed, not just absolute numbers.
  • Show detailed cost table alongside the three layers to demonstrate real cash flow, not just mortgage-rent gap.

Step 5a — Money Left In Framework (NEW — 2026-05-19)

For BRRR deals specifically, the core purpose is capital recycling. Money Left In is the primary BRRR success metric.

Money Left In = Total All-In Cost − New Mortgage Proceeds
Total All-In Cost = Purchase + SDLT + Legal + Survey + Broker + Refurb + Contingency + Refinance Fees
New Mortgage Proceeds = (ARV × Valuation Gap Factor) × LTV Ratio
Valuation Gap Factor = 0.85-0.95 (surveyor vs open market gap of 5-15%)
  • £0 (Ideal) → Full capital recycling. ROE is infinite.
  • <£10,000-£15,000 → Acceptable. Capital mostly recycled.
  • £20,000+ → CAPITAL TRAP — the BRRR has failed its core purpose. Flag for refurb optimisation or reject.
  • ROCE = (Annual Net Cashflow ÷ Money Left In) × 100. Target ≥ 15% if capital remains deployed, infinite if fully recycled.
  • Real example: £140k purchase + £25k refurb + £7k fees = £174k all-in. Projected ARV £200k → surveyor at £185k → £138.75k mortgage → Money Left In = £39k. After 15% refurb overrun, deal traps £39k — a capital trap. (Source: Property Filter)

Step 6 — Strategy Fit

  • Match property to strategy based on: condition, location, price, licensing, exit options
  • Run 3-scenario analysis: BTL (primary), sell (secondary), HMO/SA (tertiary)
  • Thresholds per strategy: BTL gross yield ≥6% (WM), BRRR equity created ≥20% cost, Flip net profit ≥20%, HMO room yield ≥12%

Step 7 — Sensitivity & Scenario Analysis

  • Stress test: +2% mortgage rate, -10% rent, +5% voids, +15% refurb overspend
  • Mortgageability: standard construction? EPC ≥ C? No cladding? Lease >80 years?
  • Exit blockers: licensing unresolved, incomplete completion certs, EPC below lender threshold
  • Cross-collateralization risk: monitor combined LTV ratios across portfolio
  • Mortgage Rate Sensitivity: Model at base rate, +2%, and -1.5%. A 1.5% rate swing can more than double or halve ROI.
  • Refinance Cycle Impact (NEW): Model post-refi cashflow at current 2026 rates plus 0.5% buffer. With 1.8M UK mortgages resetting by 2027, a deal that works on a 2021 fix may fail on a 2026 reset.
  • A deal that only works under perfect conditions is rarely a good deal.

Step 8 — Maximum Offer Price

Method A: Residual Bid (BRRR / Flip)

Max Bid = Post-Refurb GDV − Construction − Finance − Legal − Holding Costs − SDLT − Contingency − Target Profit (20% min)
  • If vendor wants more → walk away. "The numbers never lie."

Method B: Ceiling Price (BTL)

Ceiling Price = Price at which target net monthly cashflow is achieved
Work backwards: Target CF + Monthly Costs → Required Rent → Max Purchase Price
  • Define target minimum cashflow (e.g. £300/mo for WM BTL)
  • Calculate total monthly costs: mortgage + management (10%) + maintenance (5%) + insurance + voids (5%) + service charge
  • Run sensitivity: what purchase price achieves the target at current rents and rates?
  • Rule: If asking price > ceiling by <10% → negotiate. If ≥10% → PASS.
  • Include Ceiling Price in every Deal Card as a separate row showing max bid and gap to asking

Step 9 — Risk Assessment

  • Market risk: price volatility, liquidity changes. Local market understanding is essential.
  • Regulatory & compliance risk: licensing requirements, EPC regulations, planning constraints. Ignoring regulatory risk can undermine returns.
  • Execution risk: contractor delays, cost overruns, poor project management. Strong analysis anticipates execution risk rather than reacting to it.
  • Refinance risk (2026-specific): tighter lender criteria on EPC, compliance, valuation evidence. Score refinance readiness. Below 60% → HIGH RISK.

Lender Minimum: ≥ 125-145%

Detailed Cost Cash Flow Table (New — 2026-05-19)

True Net Monthly CF = Gross Rent − [Mortgage(Stress Rate 5.5-7%) + Management(12%) + Maintenance Reserve(10%) + Void Allowance(8.33%) + Insurance(£35/mo) + Compliance(£25/mo)]
⚠️ The gap between "Rent − Mortgage" and "Rent − All Costs" can exceed 100% of expected surplus.
Example: £850 rent − £580 mortgage = £270 surplus. After all costs: −£48/mo (loss of £318/mo vs expectation).

Leverage Proceeds Stress (New — 2026-05-20)

Adjusted Refi Proceeds (Stress) = ARV × 0.85 × 0.75 = ARV × 0.6375
Combines 15% leverage-collapse + surveyor gap adjustment with 75% LTV.
Use as the STRESS scenario for refinance viability.
Example: £200k ARV → £127,500 stress proceeds vs £150,000 standard (£22,500 less).

Capital Trap Ratchet (New — 2026-05-20)

Total Capital Trap = RefurbOverrun + (SurveyorGap × LTV)
Where SurveyorGap = ARV × 0.05 to 0.15
The trap compounds non-linearly — overruns compound with valuation gaps.
Rule: If (RefurbOverrun + Gap × LTV) × 1.5 > acceptable Money Left In → REJECT

Price-to-Rent Ratio (New — 2026-05-20)

Price-to-Rent = Purchase Price ÷ Monthly Rent
Target: < 100× (aspirational) | < 150× (acceptable for WM)
100× monthly rent ≈ 12% gross yield. 150× ≈ 8% gross.
Above 170× for WM BTL → the deal is speculation, not investment.

Total Cash Needed (New — 2026-05-22)

Total Cash Needed (WM BTL) = Deposit (25%) + SDLT (3%) + Legal (£1.5k) + Survey (£500) + Broker Fees
Rule of thumb: Budget 5% extra above deposit for all fees. For £200k property: £54,500+ total.

Maintenance Budget (Annual) = Property Value × 1.5% to 2%
Covers roof repairs (£5-10k), boiler replacements (£3-4k), emergency callouts. Not captured in %-of-rent budgeting.

Rental Coverage Stress Test (New — 2026-05-22)

Rental Coverage Stress Test = Gross Annual Rent ÷ (Loan Amount × 5.5% Stress Rate)
Lenders require 125-145% coverage at stress test rates (5.5-7%), not product rates (4-5%).

Net Yield Reality Check (New — 2026-05-20)

UK Average Gap: Gross 5.0% → Net 3.6% (1.4pp gap = 28% of gross)
Birmingham Case Study: Gross 6.6% → Net 1.28% (5.3pp gap = 80% of gross)
WM BTL Rule: Apply minimum 50% reduction from gross yield to net yield when screening.
If gross yield is 7%, screen at 3.5% net. If 8%, screen at 4% net.

⚠️ Common Mistakes Archive

2026-05-14
  • Buying for capital appreciation not yield — Buy as if prices will never rise. Base model on instant profitability from rent appreciation is a bonus.
  • Over-killing the refurb — Do the bare minimum that rents/sells. Avoid TV-inspired over-optimisation.
  • Not creating a maintenance fund before buying — Set aside 10% of monthly rent into a separate savings pot.
  • Securing bridging without refinance path — Engineer the exit before acquisition. Ensure property meets mainstream refinance criteria.
  • Ignoring the six-month rule — Most BTL lenders enforce 6 months from Land Registry registration. Budget 8-9 months bridging.
  • Not preparing a valuation pack for the surveyor — Provide comps, works schedule, completion certs. Surveyor defaults to conservative AVM otherwise.
2026-05-15
  • Not calculating a Ceiling Price — Evaluating a property only at asking price without working backwards from target cashflow. A property at £150k might yield £200/mo, but if your ceiling for £350/mo target is £130k, you need a discount. This is a different analysis than BRRR residual valuation.
  • Ignoring Section 24 in net cashflow projections — Many deal calculators show net profit before tax. For personal-name BTL at 40%+ marginal rate, the tax drag can turn a positive cashflow deal negative. Always model after-tax cashflow.
