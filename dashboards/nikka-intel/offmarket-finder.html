🏢 Channel 3: Companies House Liquidation Watch — 🔲 Ready to Build

🎯 How It Works

When a property company is dissolved, its assets become bona vacantia (Crown property). Pre-dissolution, directors must sell off assets. The Companies House API lets us track this in real-time.

  • API: GET https://api.company-information.service.gov.uk/dissolved-search/companies
  • SIC codes: 68100 (buying/selling), 68209 (letting), 68320 (management)
  • Filter: company_status=liquidation|dissolved|administration
  • Area: Filter by registered address in WM postcodes (DY, WV, B, WS)

📋 Implementation

Step 1: Get free CH API key at developer.company-information.service.gov.uk

Step 2: Build daily scraper: query dissolved-search with SIC 68100 + postcode filter

Step 3: Check Gazette notice for property status — contact directors before dissolution

Step 4: Cross-reference dissolved companies with Land Registry property titles

⏳ Needs API key + script

📞 Outreach Script

"Hi [Director], I see [Company Name] is being dissolved. I'm a property investor — are you looking to sell the company's property assets before striking off? I can move quickly, cash buyer, no chain."

🎯 Hit rate: Directors under time pressure to dispose of assets before dissolution deadline. Usually 2-3 month window.

⚰️ Channel 5: Probate Property Signals — 🔲 Ready to Build

🎯 How It Works

When a sole property owner dies, the executor must obtain probate and then either assent (AS1) or transfer (TR1) the property at Land Registry. Joint tenants file DJP. These filings signal unlisted properties about to hit the market.

  • Probate Registry: Grants of probate published weekly — search by name/area
  • Land Registry: Forms AS1, TR1, DJP filed after death — available via official search
  • The Gazette: Legal notices include probate grants — free to search
  • Death notice scanning: Local obituaries matched to property addresses

📋 Implementation

Step 1: Search The Gazette (thegazette.co.uk) for probate notices in WM postcodes

Step 2: Cross-reference with Land Registry title register via HMLR search

Step 3: Check if property is already listed — if not, executors likely still deciding

Step 4: Approach executors early — probate can take 6-12 months, offer to wait

⏳ Needs Gazette scraper + HMLR lookups

📞 Outreach Script

"Hello, I understand you're the executor of [Name]'s estate. I'm a local property investor and I buy properties directly, often before they reach the market. If you're considering selling the property at [Address], I can make a fair cash offer and work around your timeline — even if probate is still in progress."

🎯 Angle: Executors often want a quick, hassle-free sale. No estate agent fees, no viewings, no chain.
