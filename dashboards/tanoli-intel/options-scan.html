📖 How to Read This Page

  • 🟢 Call Buy / Bullish Call — Someone bought CALL options expecting the stock to go UP. If you agree, consider buying the same call.
  • 🔴 Put Buy / Bearish Put — Someone bought PUT options expecting the stock to go DOWN. If you agree, consider buying the same put.
  • Stock — The ticker symbol of the stock seeing unusual options activity.
  • Strike — The price level they're betting on. Stock must cross this for the option to be profitable.
  • DTE — Days until expiry. Fewer days = trade needs to happen faster.
  • Vol/OI — Today's volume vs open interest. 10x+ means very unusual activity.
  • Score — Combined metric. 500+ = notable, 1000+ = very unusual, 5000+ = extremely rare whale activity.
  • Expected Moves — How far the stock is expected to move (up or down) based on ATM straddle pricing.
